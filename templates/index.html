How It Works

This tool processes Loan Origination System (LOS) logs to create a clean status history report.

  1. Upload a text file containing LOS data (like the Dealer_887.txt example)
  2. The system will extract and organize the data by status changes
  3. You'll receive a clean JSON file with the status history, showing when each status started and ended

The processed output will show:

  • Sr. No - Sequential number for each status change
  • Status name (e.g., "Lead Uploaded", "Application In Progress")
  • Status start time (Unix timestamp)
  • Status start time in human-readable format (YYYY-MM-DD HH:MM:SS)
  • Status end time (Unix timestamp)
  • Status end time in human-readable format (YYYY-MM-DD HH:MM:SS)
  • User ID who initiated that status change
  • Phase and task information
